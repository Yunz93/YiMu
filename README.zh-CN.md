# YiMu · 一目

**让每一手，都看得懂。**

[English](README.md) | 简体中文

[![一键部署到 Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FYunz93%2FYiMu&project-name=yimu&repository-name=YiMu)

YiMu 是一个面向围棋初学者的交互式学习网站。如果你一直弄不清围棋规则、不知道怎么算目数，也看不懂一手棋对局面的影响，可以从这里开始：边落子、边看讲解，与浏览器里的 AI 陪练一起学习。

网站界面目前使用**简体中文**，项目说明提供中英文两个版本。

## 功能

- **落子音效**：你与 AI 的合法落子、课程里的实际落子会播放短促的落盘声；预览、悔棋、停一手、死棋标记和恢复存档保持安静。顶部工具栏及全屏工具栏的喇叭按钮可开关音效，设置保存在本机。浏览器首次交互后才启用声音。
- **落一手，懂一步**：按实际局面区分救棋、补强、打吃、紧气、连接、断点、呼应、接近、提子与可能的填眼。用坐标指出受影响的棋块，对比落子前后的气数，并提醒自身被提、脱先未救等风险；旧存档的讲解也会更新。
- **知道为什么推荐这里**：点击「给我提示」查看推荐的具体依据、代价、搜索中考虑的一种合法对手应手，以及其他搜索过的候选点。关闭详情后，推荐仍保留在讲解卡片中；落子和试落详情也会说明后续应观察什么，查看讲解不会自动落子。
- **落子前预览**：电脑鼠标悬停，手机或平板长按约 0.4 秒，即可查看气、提子、势力和估算占点变化；长按时拖动可换点，浮动提示会显示当前影响，松手收起且不会落子。轻点仍立即落子，无需二次确认。预览不会修改棋局、学习统计或触发 AI。预览可随时关闭，并记住开关设置。
- **棋盘全局模式**：点击棋盘右上角「全局模式」，收起侧栏和课程。横向大屏将比分、预览和操作放到侧边，优先让棋盘占满可用高度；窄屏使用紧凑工具栏和浮动试落信息。「看懂棋盘」仍在棋盘下方。悬停、长按和关闭预览不会改变棋盘尺寸；19 路棋盘可完整显示，无需横向滚动。点击「退出全局」或按 Esc 返回，棋局和 AI 思考不中断。
- **四种棋盘视图**：棋盘、气、势力和地盘。在「气」视图点击棋子，观察整块棋共享的气。
- **智能陪练**：三档搜索程度，支持提示、悔棋、选择执黑或执白，以及 9 路／13 路／19 路标准棋盘。
- **统一学习中心**：课程和学习进度集中在同一个入口，展示已完成课程、亲手落子和完成棋局数；可继续第一节未完成课程，按主题与完成状态筛选，返回课程列表时保留筛选条件。16 节互动课涵盖基础规则、打吃救子、提子例外、打劫、假眼、单官、公活、死子标记、停一手、19 路坐标及三四路布局，每课均可复习。
- **看懂分数的来源**：采用中国规则面积计分，白贴 7.5 点；未定区域单独显示，终局手动标记死子后数子，有争议时可以返回继续对弈。
- **自动保存进度**：棋局、落子次数、已完成课程和完成棋局数保存在当前浏览器的 `localStorage` 中。
- **轻量且适配手机**：原生 HTML、CSS、JavaScript 模块，无运行时 npm 依赖，不需要后端、数据库或 AI API Key。

## 一键部署到 Vercel

点击上方 **Deploy with Vercel** 按钮，登录 Vercel，选择 Git 账号及新仓库名称，点击 **Deploy**，即可创建一份项目副本并发布自己的围棋学习网站。

仓库内的 [`vercel.json`](vercel.json) 已提供以下配置：

| 设置 | 值 |
| --- | --- |
| 根目录 | 仓库根目录 |
| Framework Preset | Other |
| Node.js | 24.x |
| Install Command | `npm ci --ignore-scripts` |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| 环境变量 | 无需配置 |

网站静态源码直接位于 `dist/`，构建命令负责检查必要资源和 JavaScript 语法，不进行打包或代码生成。Vercel 根目录应保留为**仓库根目录**，`dist` 只作为输出目录，不要把两者混淆。无需配置 SPA 重写规则。

也可以在 **Vercel → Add New → Project** 中导入 `https://github.com/Yunz93/YiMu`，使用相同配置进行部署。

## 本地运行

需要 **Node.js 24**、npm，以及用于本地静态服务器的 **Python 3**。

```sh
git clone https://github.com/Yunz93/YiMu.git
cd YiMu
npm ci
npm run dev
```

浏览器打开 **http://localhost:4173**。开发服务器直接提供 `dist/` 中的文件。请通过 HTTP(S) 访问，不要直接双击 `index.html` 使用 `file://` 打开，否则 ES Modules 和 AI Worker 可能无法加载。

运行检查：

```sh
npm test
npm run build
```

新增测试验证预览不修改原局面、19 路棋盘边界、劫与公活课程棋形、标准棋盘坐标。原有测试覆盖共享气、整块提子、禁自杀及提子例外、局面超级劫、占用点与越界、中国规则计分、死子移除、空盘估算及落子讲解。

全屏布局还可使用真实 Chromium 做回归检查（可选开发依赖）：

```sh
python3 -m pip install playwright
python3 -m playwright install chromium
python3 tests/browser/fullscreen.py
python3 tests/browser/settings.py
python3 tests/browser/sound.py
```

此检查会启动临时本地服务器，覆盖 9／13／19 路棋盘的桌面、平板、手机和横屏尺寸，并验证预览不挤动棋盘、缩放、落子与 AI 应对，以及新开局选项文字完整显示。安装了系统 Chromium 时会直接使用。

140 毫秒的落盘声由本地合成。修改 `dist/stone-sound.js` 中的 `stoneSamples()` 后，运行 `npm run build:sound` 重新生成微信 WAV 资源；`npm run check:sound` 验证三个版本的音效一致。

## 学习与试落

1. 可从 9 路入门，或在对局设置中选择「19 路 · 标准棋盘」，使用完整 361 个交叉点。手机上标准棋盘在面板内横向滚动。
2. 默认开启落子前预览：鼠标悬停查看试落，点击或轻触交叉点立即落子，无需确认按钮。手机长按约 0.4 秒预览、按住拖动换点，松手不落子；长按激活前滑动仍可正常滚动页面或棋盘。电脑移开鼠标或按 Esc 收起预览；方向键可移动并预览，回车立即落子。预览可随时关闭，刷新后保留设置。
3. 「学习中心」统一展示 16 节分类互动课、学习进度和下一节未完成课程；可按主题、待学习或已完成筛选，也能复习已完成课程。课程编号与本地存储保持不变，旧进度会继续保留。
4. 可以在气、势力、地盘视图下，通过鼠标悬停或方向键查看试落。估算只针对这一手之后的局面，不包括 AI 的后续应对，也不等于确定地盘。

## 规则与计分

黑棋先行，同色棋子直线相连后共享气，没有气的整块棋会被提走。禁止自杀落子；如果落子后能先提走对方棋子、获得气，则可能合法。本站采用**局面超级劫规则**，禁止落子后重复此前出现过的棋盘布局。可以停一手，双方连续停一手后进入数子，也可以手动进入教学数子模式。

终局按双方的**活棋数量＋围住的空交叉点**计算，白棋额外获得 **7.5 点贴目**，中立空点不计入任何一方。提掉的棋子不会作为提子数重复加分。结果展示双方的面积差「点数」；换算成传统中国规则胜负「子数」时，取这个差值的一半。

对弈中的势力和占点根据棋子距离进行启发式估算，未确定区域会单独显示。连接、提子和包围都可能使估算结果发生明显变化。

## AI 与学习边界

AI 在浏览器的独立 **Web Worker** 中运行，结合战术候选评分、对手应手搜索和随机模拟选点。三档难度使用不同的搜索预算。它定位为入门陪练，没有经过段级位评定，也没有接入 KataGo。

落子讲解对比落子前后的棋块、气数和棋形，推荐详情还会展示搜索实际返回的应手与备选点，不是 AI 模型的内部思考过程。应手示例会检查超级劫等合法性，但只是可能走法，不表示对方一定这样下，也不保证推荐是最优解。势力不等于确定地盘。复杂死活不会自动判定：终局需要自行标记已确定的死子，不确定时继续对弈验证。计分器假定未标记移除的棋子均为活棋。

## 数据与隐私

棋局和课程进度保存在浏览器 `localStorage`，不会跨浏览器、跨设备同步，清除存储后进度会消失。网站不会把棋局发送给应用后端或 AI 服务。中文字体通过 Google Fonts 加载，加载失败时使用系统字体。托管平台可能处理常规访问日志。
