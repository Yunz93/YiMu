# YiMu · 微信小程序版

原生微信小程序，包含「学习棋局」「学习中心」「互动课程」「关于一目」。棋盘使用 Canvas 2D，AI 在微信 Worker 中运行；无需后端、微信登录、外部 AI Key 或云开发环境。

## 导入运行

1. 在仓库根目录执行：

   ```sh
   npm ci
   npm run build:wechat
   npm test
   ```

2. 安装微信开发者工具，选择「小程序」下的「导入项目」（不要选择「小游戏」），**目录选择本文件所在的 `wechat/`**，而非仓库根目录或 `dist/`。`project.config.json` 已将 `miniprogram/` 设置为代码目录。
3. 使用**普通小程序账号**的真实 **AppID** 导入（小游戏 AppID 不适用于本工程）；也可以修改 `project.config.json` 的 `appid`。仓库默认 `touristappid` 仅供工具允许范围内的本地查看，无法用于提交正式版本；测试号的功能限制以开发者工具提示为准。
4. 选择支持 Canvas 2D 和 Worker 的当前稳定基础库，编译后查看默认棋局页面。项目已开启增强编译。
5. 用开发者工具的预览功能扫码，在安卓、iPhone 上检查触屏和 AI。代码无需服务器域名白名单，开发期间也不需要关闭域名校验。

AppID 不是 AppSecret。**不要把 AppSecret、上传密钥或个人证件放进代码。** `project.private.config.json` 已被 Git 忽略。

## 报错：找不到 `miniprogram/game.json`，环境显示 `mg`

本仓库现已提供可用于小游戏 AppID 的[小游戏工程 `wechat-game/`](../wechat-game/README.zh-CN.md)。如果你的账号是小游戏，请直接导入该目录。

这表明开发者工具正在按**小游戏**加载。当前工程是普通小程序，入口是 `app.js`／`app.json`，没有 `game.json` 是正常的。

1. 关闭当前项目，回到开发者工具项目列表，在「小程序」入口重新导入。目录选择 `wechat/`，此目录中应能看到 `project.config.json`。
2. 确认该文件包含 `"compileType": "miniprogram"` 和 `"miniprogramRoot": "miniprogram/"`。
3. 检查本地 `project.private.config.json`；若包含 `compileType: "game"` 或错误代码目录，修正对应字段。保留其他账号和工具设置，不需要删除整个文件。
4. 确认使用的是**普通小程序 AppID**，而非小游戏 AppID。不确定时到公众平台确认账号类型；需要本地试运行时选择普通小程序测试号，而非小游戏测试号。
5. 若配置和账号类型均正确，清除工具缓存并重新编译；如项目记录仍保留小游戏模式，移除工具中的旧项目记录后重新导入，**保留本地源文件**。

运行 `npm run check:wechat` 会检查主配置、本地配置和入口路径，但无法从 AppID 字符串判断微信账号类型，也不能改变工具已缓存的导入模式。

不要创建空的 `game.json`，也不要把 `app.json` 改名。小游戏的入口和页面运行方式不同，不能通过补一个配置文件转换。如果实际要发布为小游戏，请使用已提供的 `wechat-game/` 工程。

## 功能

- 9／13／19 路棋盘，选择执黑或执白，三档本地 AI 搜索；默认认真思考。
- 轻点立即落子；长按约 0.4 秒预览，按住拖动换点，松手不落子；预览开关保存在本机。
- 气、势力、地盘视图及全局棋盘模式；缩放布局不重置棋局，全局切换不中断 AI。
- 落子讲解区分救棋、补强、打吃、紧气、连接、断点、呼应、填眼等；推荐详情展示真实搜索返回的应手与备选点。
- 悔棋、停一手、双方连续停一手进入数子；整块标记死棋，中国规则面积计分，白贴 7.5 点；结果只累计一次。
- 学习中心统一展示课程与统计，可按主题及完成状态筛选，继续第一节未完成课程。
- 全部 16 节课程原生交互，包括劫、公活、死子标记、停一手和标准棋盘坐标。
- 分享课程和首页；「关于一目」提供隐私说明、微信意见反馈和本机进度清除。

切换到其他页面或进入后台会终止正在运行的 Worker；返回对局页时，如仍轮到 AI，会重新搜索。迟到的搜索结果不会修改棋局。Worker 启动或搜索失败时显示重试，不会在主线程强行运行完整搜索。

## 共用规则与代码更新

网页版 `dist/engine.js`、`dist/lessons.js` 和 `dist/ai.js` 是核心逻辑来源。`npm run build:wechat` 生成小程序可使用的 CommonJS 文件：

```text
shared/engine.js      共用围棋规则、计分、讲解、纯预览
shared/lessons.js     共用16节课程数据
workers/engine.js     Worker隔离环境内的同一份规则
workers/search.js     共用AI搜索，计时适配为 Date.now()
```

**请勿直接修改这些生成文件。** 修改网页版核心后重新构建，并把生成结果一起提交。运行 `npm run check:wechat` 检查生成结果是否过期，同时校验页面文件、JS、JSON 和源码包体积。`npm run build` 仍只构建／检查网页版，Vercel 继续发布 `dist/`。

小程序界面、会话状态、触屏识别及课程交互位于 `pages/`、`components/`、`utils/`，不依赖 DOM、浏览器存储或浏览器 Worker。

## 存储与隐私

- 棋局、课程完成记录、累计统计和预览设置使用微信本地存储，不会自动同步到其他设备或网页版。
- 不调用登录、位置、相册、通讯录等接口；不接入统计、广告、第三方 AI 或网络字体。
- 窗口尺寸与像素比仅在本地用于棋盘适配。
- 复制网站／开源地址时使用微信剪贴板功能；意见反馈使用微信原生入口。
- 当前版本未提供网页版存档导入。不能把浏览器 localStorage 当作已迁移的小程序存档。

本地隐私说明位于「关于一目」。正式提交时还要按微信后台要求配置用户隐私保护指引，内容应与实际发布版本一致。

## 上线前需要补充

1. 使用真实小程序 AppID，并配置开发者和体验者。
2. 先向平台确认**教学课程加完整人机对局**适用的服务类目，以及普通小程序／小游戏接入要求。本工程是 `compileType: miniprogram` 的普通原生小程序实现，代码不代表平台已认可类目或审核通过。
3. 办理小程序备案，准备主体及负责人材料；若后台对类目要求额外资质，按要求补充。
4. 在 `miniprogram/config.js` 填写真实 `filingNumber` 和公开的 `contact`（如需），不要使用示例备案号。备案号配置后会展示在「关于一目」；同时完成微信后台要求的官方备案信息展示。
5. 配置正式名称、图标、简介、隐私指引、审核说明及功能截图。代码包暂未包含用于公众平台账号设置的图标与审核截图。
6. 使用开发者工具上传体验版，完成真机验收后提交审核，通过后发布。**GitHub 推送、Vercel 部署均不等于微信上传或发布。**

审核说明可参考：

> 本小程序无需注册或登录。首页可进行围棋人机练习，轻点落子，长按预览局面影响；学习中心提供16节互动课程与本机学习记录。AI计算与数据保存均在设备本地完成。关于页面提供隐私说明、意见反馈和数据清除。

## 验证范围

仓库测试覆盖全部课程的完成路径、规则共用、19路预览和坐标、存档与悔棋、计分锁定、学习进度合并、Worker 消息与失效结果拦截、页面生命周期，以及 Canvas 组件的触屏事件链。

开发环境已通过 WXML／WXSS 官方编译器封装的编译检查。平台 API 与 Canvas 交互测试使用模拟环境，**不等于微信开发者工具运行或真机验收**。首次导入真实 AppID 后至少验证：

- 安卓／iPhone 上9、13、19路的轻点、长按拖动、滑动取消和松手不误落子。
- AI三档、执白先由AI落子、搜索中悔棋、切页、切后台及恢复。
- 普通／全局模式、设备尺寸变化、预览关闭后的直接落子。
- 16课、错答反馈、已完成复习、课程返回后的筛选和统计。
- 提子、劫、停一手、死棋标记、结果确认与本地存储失败提示。
- 分享路径、意见反馈及公众平台隐私／备案配置。
